API Contract

Frontend sends irradiation, ambient_temp, module_temp, and hour to Flask. Flask returns predicted loss, severity, action, model metrics, and derived physics features.

Leakage Fix

The deployed model avoids using DC_Power or AC_Power as input because those are not available before prediction. This makes the website a real inference system instead of a formula demo.

Dataset

If Kaggle Plant 1 CSV files are present, Flask trains from them. If not, it trains from a realistic synthetic physics dataset so the project still runs for demonstration.
